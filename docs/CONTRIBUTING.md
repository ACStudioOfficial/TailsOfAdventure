# Contributing to Tails of Adventure

Welcome! If you are here, you want to help us build a decentralized,
open-source animated series. We value every contribution: from fixing
a typo in a script to suggesting a complex world-building mechanic.

---

## 1. Before You Start

* Read the Series Bible: `docs/BIBLE.md`
* Read the Script Format: `docs/FORMATTING.md`
* Read the Code of Conduct: `CODE_OF_CONDUCT.md`

These three documents define the universe. Everything else follows from them.

---

## 2. No Git Experience? No Problem

You do not need to be a developer to contribute. The simplest way:

1. Find something to fix or suggest
2. Open the **Issues** tab and click **New Issue**
3. Describe your idea in plain language

For direct file edits:
1. Open any `.md` file in the repository
2. Click the pencil icon (Edit this file)
3. Make your changes
4. Click **Commit changes**. Think of it as "Save with History"

That's it. GitLab handles the rest.

---

## 3. For Writers and Lore Contributors

* All scripts MUST follow `docs/FORMATTING.md`
* All lore MUST be consistent with `docs/BIBLE.md`
* Markdown (`.md`) only, meaning no `.docx`, no `.pdf`, no proprietary formats
* Submit via Pull Request, or discuss in Issues first if unsure

**Canon policy:** Contributions accepted into the main branch become
canon. Forks are non-canon unless explicitly merged by the BDFL.

---

## 4. For Artists

* Reference sheets must be submitted in `.png` or `.svg` format
* Style must be consistent with existing reference sheets
* By submitting art, you confirm you hold the rights to the work
* See `docs/ART_GUIDELINES.md` for visual consistency rules

---

## 5. Our Tech Stack

To keep the project sovereign and accessible, we use only
FLOSS (Free/Libre Open Source Software):

**Production:**
* Eden emulator - game capture
* Kdenlive/Blender - video editing
* CachyOS - reference operating system

**Repository:**
* Git - version control
* Markdown - all documentation and scripts
* GitLab - hosting and collaboration
* GitHub - repo's mirror

We do not accept contributions that require proprietary tools
to view, edit, or reproduce.

---

## 6. Content Rules

1. **No raw AI-generated content.** Scripts and art must reflect
   genuine human creative decisions. AI tools may assist, but
   the creative intent must be demonstrably yours. If we cannot
   tell a human made meaningful decisions, it will be rejected.

2. **No proprietary formats.** If it cannot be opened in an
   open-source tool, we cannot use it.

3. **Follow the script format.** Submissions that ignore
   `docs/FORMATTING.md` will be returned for revision.

4. **Follow the Code of Conduct.** See `CODE_OF_CONDUCT.md`.

---

## 7. Governance and Final Authority

Tails of Adventure operates under a BDFL (Benevolent Dictator
For Life) model. Peter Nikitenko (ACStudio) holds final authority
over:

* Canon decisions
* Merge approvals
* Commercial exception grants
* Project direction

This is not bureaucracy. It is transparency. Every significant
decision will be documented publicly in the repository.

---

## 8. Licensing and Commercial Transparency

By contributing, you agree your work is licensed under
**CC BY-NC-SA 4.0**. Here is exactly what that means:

**You retain:** Authorship credit, always cited.

**The community gets:** The right to use, share and build
upon your work for non-commercial purposes under the same license.

**Commercial use:** Tails of Adventure intends to generate
revenue through the following channels when eligible:
* YouTube monetization
* Patreon supporter funding

This revenue will fund production costs and contributor
compensation (voice actors, artists, etc). This is explicitly
permitted under CC BY-NC-SA as the Licensor (ACStudio)
generating revenue from the primary work, not third parties
commercializing contributions without permission.

**Third party commercial use** of any content from this repository
requires explicit written permission from ACStudio. Violations
will be enforced under the NC clause.

Commercial exceptions may be granted by the BDFL on a case by case
basis and will be documented publicly.
