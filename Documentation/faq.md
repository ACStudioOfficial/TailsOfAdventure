  ## This file is dedicated to those, who have any questions or are interested in, but not too sure about the series

**Q:** Why it took so long?  
**A:** Because it's my hobby. I'm trying to make something, that i'm eagered to (making animations) and something that I enjoy (Linux), so the initial release was a bit clunky

**Q:** Why machinima in "Animal Crossing: New Horizons" and not even 2D or 3D animation?  
**A:** Because my series dates all the way on March 20th, 2021, 1 year anniversary of ACNH. At that time, I was charmed by the game and wanted to make something, but nothing worked, so I've started tweaking up the formula. Yes, I has hiatuses during development, but that got me even more ideas, which I've implemented here. And going back to the question, no idea. Honestly. I just like making machinimas in ACNH and it has it's own charm

​**Q:** Wait, are you using AI? I saw some weird paths...  
**​A:** Fair question. I get why you'd be skeptical, especially considering AI slop.  
But here is the reality: The foundation for Tails of Adventure was born in March 2021, and Season 1 ran from August 2023 through October 2024. This project existed as a purely human-driven passion project long before "AI slop" became a thing, and you can verify that history on YouTube.  
​The AI in this repo is a very recent addition and it was used exclusively to scaffold the file structure to save time on boring fillings of this repo. It turns out the AI was a bit overconfident and hallucinated some paths that look like legitimate paths, but are actually just straight up nonsense. I’m currently scrubbing that wreckage.  
**​Tails of Adventure is 100% human-made.** Don't let a few bad folder paths make you think otherwise. If you see something that looks like an "AI glitch", it’s just me being an incompentent human developer who let a machine handle the laundry and it messed up the sorting. If you find something ugly or broken, open an issue. I’d rather fix it properly than let it stay broken.

**Q:** You have some remanence of Linux  
**A:** Yeah, about that... For this repository, I've used Linux kernel source code (7.0.12 if you're interested in) as the reference for my repo, hence why it's so similar. But generally, I want my series to be "Linux of indie-animations",  where you can do basically anything from "You've spelled impendence wrong in S2E3" to "Fuck it, Pony Tails and Wey and the lore is bigger than Warhammer 40,000"

**Q:** Why some of your elements are spelled, like it's for the kids?  
**A:** That's because writers aren't developers. They know nothing about Git or "How to make a push to a Git repository". I specifically tried to make each element of the workflow understandable for non-developer people

**Q:** Do I need Linux to contribute to it?  
**A:** No. Use ANY OS you like, like Windows, macOS, Android, iOS or even ReactOS or TempleOS. The whole point of ditching .docx and .pdf towards .md is that you can use any device with a basic text editing software and Internet access. The "Our Tech Stack" in `Documentation/contributing.md` is just a showcase of what i'm using
